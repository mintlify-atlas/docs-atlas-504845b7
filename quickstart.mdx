## Prerequisites

Before running kbot, make sure you have:

- Python 3.9 installed
- The repository cloned to your machine
- Dependencies installed via `python3.9 -m pip install -r requirements.txt`

If you haven't done these steps yet, see the [Installation](/installation) guide.

## Play by quiz ID (no account required)

If you know the UUID of the quiz, you can join a game without a Kahoot account.

<Steps>
  <Step title="Get the game PIN">
    Ask the game host for the PIN displayed on their screen. The PIN is typically a 6-digit number.
  </Step>

  <Step title="Get the quiz ID">
    The quiz ID is a UUID in the format `xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx`. The host or quiz creator can find this in the Kahoot dashboard URL:

    ```
    https://create.kahoot.it/details/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
    ```
  </Step>

  <Step title="Run kbot">
    From the repository directory, run:

    ```bash
    python kbot -n MyNick -p 123456 -i xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
    ```

    Replace:
    - `MyNick` with the nickname you want to appear as in the game
    - `123456` with the actual game PIN
    - `xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx` with the quiz UUID
  </Step>

  <Step title="Watch kbot play">
    Once connected, the terminal shows the bot authenticating and receiving answers:

    ```
    AUTHENTICATED
    ANSWERS RECEIVED
    Question 1
    SELECTED BLUE
    Question 2
    SELECTED RED
    Question 3
    SELECTED GREEN
    ...
    GAME OVER
    ```

    The bot submits each answer automatically as questions appear in the live game.
  </Step>
</Steps>

## Play by quiz name (account required)

If you know the quiz's name but not its UUID, use the `-q` flag along with your Kahoot credentials.

<Steps>
  <Step title="Run kbot with your account credentials">
    ```bash
    python kbot -n MyNick -p 123456 -q "My Quiz" -e user@example.com -a password
    ```

    Replace:
    - `MyNick` with your desired nickname
    - `123456` with the game PIN
    - `"My Quiz"` with the quiz name to search for
    - `user@example.com` and `password` with your Kahoot account credentials

    <Warning>
      Your password is passed as a plain-text argument. Avoid running this command in shared environments or leaving it in your shell history.
    </Warning>
  </Step>

  <Step title="Watch kbot play">
    The output looks the same as when using a quiz ID:

    ```
    AUTHENTICATED
    ANSWERS RECEIVED
    Question 1
    SELECTED YELLOW
    Question 2
    SELECTED BLUE
    ...
    GAME OVER
    ```
  </Step>
</Steps>
